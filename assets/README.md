# FocusForge Assets

Place application assets in the matching folder:

- `images/` - interface images and illustrations
- `logos/` - Steam and other protected-app logos
- `icons/` - toolbar, tray, and application icons
- `sounds/` - focus-start, focus-complete, and reminder sounds
- `fonts/` - approved font files
- `backgrounds/` - optional dashboard backgrounds

Tell the developer what each file should be used for, and it can be connected to the appropriate part of the app.
